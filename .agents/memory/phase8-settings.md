---
name: Phase 8 platform settings
description: Scope boundary for stored future-ready administrator configuration.
---

Administrator platform settings are intentionally inert: validate and save configuration, but do not change live marketplace behavior in this phase.

**Why:** The Phase 8 specification defines these settings as “Future-ready only.”

**How to apply:** Keep marketplace, verification, featured duration, notifications, search defaults, AI, registration, and rollout settings as stored configuration until a separately scoped implementation explicitly authorizes runtime wiring.
