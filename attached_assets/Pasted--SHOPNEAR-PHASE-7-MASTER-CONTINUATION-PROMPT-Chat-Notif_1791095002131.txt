⸻

CHAT SYSTEM

Implement secure real-time messaging.

Support conversations between:

Customer ↔ Business

Customer ↔ Service Provider

Business ↔ Customer

Service Provider ↔ Customer

Features:

* Conversation list
* Message history
* Read receipts
* Unread counters
* Typing indicator architecture
* Message timestamps
* Delivery status
* Soft delete
* Report conversation
* Block user architecture
* Conversation search

Keep the architecture modular for future media/file messages.

⸻

NOTIFICATIONS

Implement an in-app notification system.

Support notifications for:

* New message
* Favorite updates
* Business verification
* New review
* New rating
* Admin announcements
* Account activity

Features:

* Read / unread
* Mark all as read
* Notification history
* Pagination
* Notification preferences

Design it so push notifications can be added later without changing the core architecture.
